# EmailOwl for Windows (beta)

The Windows companion to EmailOwl on iPhone, iPad, Mac and Android. It pairs with your EmailOwl account and shows
the same task board, with drafting, replies, Auto Chase and your schedule on your PC.

This repository holds only the Windows releases. No source code lives here.

## Download

Get the newest build from **[Releases → Latest](../../releases/latest)** and run `EmailOwl-Setup-<version>.exe`.

- It installs for you alone, with no administrator prompt, and adds EmailOwl to the Start menu and to
  Settings → Apps → Installed apps.
- The beta is not signed yet, so Windows SmartScreen may warn the first time: choose **More info**, then
  **Run anyway**.
- Prefer not to install? `EmailOwl-Windows-x64-<version>.zip` is the same app: unzip it and run `EmailOwl.App.exe`.
  An unzipped copy tells you when a new build is out but does not update itself.

## Updates

Once installed, EmailOwl keeps itself up to date. It checks this repository shortly after it starts and every few
hours. When a newer build is ready, a banner says **Restart to update**. Restarting installs the new build in a few
seconds and reopens EmailOwl. Your data is not touched. You can also check from **Settings → About → Check for
updates**.

Before installing, EmailOwl checks every download against the size and SHA-256 published with it (`update.json` in
each release) and discards anything that does not match.

## Requirements

- Windows 10 (version 1809 or later) or Windows 11, 64-bit.
- An EmailOwl account, set up on your phone or tablet. The PC pairs with it.
